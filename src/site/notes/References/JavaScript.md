JavaScript adalah bahasa pemrograman serbaguna yang membuat website interaktif. Berjalan di browser, server (Node.js), dan aplikasi desktop. Fitur: dynamic typing, event-driven programming, evolusi konstan. Penting untuk web modern frontend dan backend.
